02 / Proposals are not decisions

The network advises. Search selects.

The policy proposes moves. Particle-based risk and searched payoffs decide between them. The neural belief and value heads do not drive the search evaluation.

observe.onnx

Runs on every observation. Inputs: planes, scalars, previous hidden state. Outputs: next hidden state, spatial features, belief logits and value.

score.onnx

Runs at our decision. Combines hidden state, source/destination spatial features, coordinates and promotion into 393 features per legal candidate. Outputs policy and danger logits.

The quality bar is still open

The shipped danger head misses about 89% of positive danger cases at its evaluated validation threshold. The value head has not shown convincing predictive quality. We have not isolated whether architecture, inputs or training is the main bottleneck. A belief-aware recurrent model and compact attention alternative must beat this unchanged control on held-out calibration, CPU cost and equal-clock paired games.

Two memories, still separate

The GRU stores learned history. Particles store explicit possible boards. The neural belief head is a set of square-wise marginals, not a joint legal board distribution, and currently does not update the particle filter. Connecting them safely is a research direction.

Offline / data to deployment

Every game becomes evidence.

Public replays feed validation, supervised learning and controlled experiments. GPU training happens offline; the submitted bot performs CPU inference.

Built · offline tool

An experience library

The first frozen index contains 263,998 actor decisions from 3,258 games. An observation packs into 32 bytes; history adds more. Context filtering and bounded top-k lookup make retrieval practical. It is not yet wired into live decisions.

Experimental

PPO & compressed latents

Recurrent PPO training code exists, but mapped arena releases use stage-A v1. VQ/RVQ retrieval codes and compressed learned state representations remain experiments to validate, not features of the shipped network.

Wider search or deeper search?

Illustrative allocation at a fixed node budget. This is not a performance prediction.

45% for the primary shortlist; 55% for matrix cells. More rows or columns leave fewer nodes per cell.

The next architectural step

Search future observations as well as possible boards. Model what the opponent can see, so a concealed attack is valued against a plausible response rather than an omniscient one.

What makes it difficult

Hidden move histories branch rapidly. Runtime must bound memory and time without manufacturing certainty. Learned likelihoods need held-out calibration; sampled risk still depends on which worlds survive.
