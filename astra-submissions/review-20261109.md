replays where a safe move existed on the true board, the deployed mask
removed every safe move. Search behind that mask cannot select an excluded
move. The new rule admits a move if either fitted or sharpened weighting
supports it. It expands options rather than guaranteeing safety, so full-game evidence matters. The pilot passed its fixed gate. The next
strength check remains incomplete. The clock-corrected Misty comparison
stopped after one late opponent timeout: four normal games, just two clean
matched White cells (candidate 1 point, control 1.5). This is inconclusive.
A resource-bounded local comparator must qualify before another comparison;
the candidate itself is unchanged. Two health games against unchanged v38
started at 00:27 UTC on November 10 (original session 19465). Both colors
must finish normally with the cap enforced; game scores do not select the
deployment. This checks a local proxy, not the arena opponent's exact setup.

The learning loop has fresh data again. The engine still uses the model
trained on 148,357 games through October 31 and its packaged history table.

and playing gates. More data alone is not a strength claim.
