The guard-union candidate does not earn a release. The qualified local
comparator later loses all consistent boards after its own Qa4. A redacted
component replay reproduces that at cap 200,000; uncapped updates finish
with six states. The failure is a reference-engine limitation, not a bot win
that supports promotion. No new full-game batch follows automatically.

The full native census is more useful than exact-board sample counts. The
true rule state survives among 2,344 worlds, but the chosen capture's failure
family has only 0.01390% sharpened mass. The ordinary 32-world sample misses
it, and both guards remove the two actual escapes. All 35,160 move/world
labels and weighted risks pass independent audit. This does not establish
population-wide calibration or the exact live belief.

The proposed next study compares ordinary/stratified worlds crossed with
old/payoff-bound root pruning on the same beliefs, first in queenless seats.
The source's bounded continuation values give a derived dominance bound,
instead of another king-risk-margin constant. Six risk signatures suffice
in the measured root. This remains a design for review, not an implemented
policy or a reason to reopen the failed candidate. Separately, ask Fable to
review history-preserving cap recovery for the local opponent.

The learning loop has fresh data again. The engine still uses the model
trained on 148,357 games through October 31 and its packaged history table.
Fable has the audited dataset manifest and a request to resolve one immutable
generation before a separate fit. A refit should distinguish newly held-out
November games from reused test games and pass predictive, belief-quality
and playing gates. More data alone is not a strength claim.

The first publication failed because exFAT does not support symlinks. That
attempt remains recorded as exit 1; its completed extraction was audited and
published without running it again. The 116 MB labelled taxonomy payload
stays on the bulk drive, with hashes in Git; readable summaries are public.
All experiment cores are released. Astra has no running benchmark, diagnostic
or GPU job. No further arena upload or version number has been allocated. This is today's review point;
Fable's response to the handoff has not yet been observed.
