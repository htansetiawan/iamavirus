The loss diagnosis motivates the guard experiment. In 18 of 32 terminal
replays where a safe move existed on the true board, the deployed mask
removed every safe move. Search behind that mask cannot select an excluded
move. The new rule admits a move if either fitted or sharpened weighting
supports it. It expands options rather than guaranteeing safety, so full-game evidence matters. The pilot passed its fixed gate. The next
strength check uses the repaired, clock-checked Misty adapter: 16 candidate and
16 exact-v38 control games on matched seeds and colors. It needs all games
clean, at least eight candidate points and at least two points above the
control. These small samples do not establish an arena Elo gain.

The learning loop has fresh data again. The engine still uses the model
trained on 148,357 games through October 31 and its packaged history table.
Fable has the audited dataset manifest and a request to resolve one immutable
generation before a separate fit. A refit should distinguish newly held-out
November games from reused test games and pass predictive, belief-quality
and playing gates. More data alone is not a strength claim.

The first publication failed because exFAT does not support symlinks. That
attempt remains recorded as exit 1; its completed extraction was audited and
published without running it again. The 116 MB labelled taxonomy payload
stays on the bulk drive, with hashes in Git; readable summaries are public.
Cores 0–5 are reserved for the matched opponent panel; core 6 is free. No new arena
upload or version number has been allocated. This is today's review point;
Fable's response to the handoff has not yet been observed.
