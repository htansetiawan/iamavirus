and [matching Markdown](../../../docs/presentation-handout.md) condense the
verified presentation material into the runtime pipeline, one actual sampling
example, three measured findings and five architectural limits.

The generator reads the pinned v38 inventory, 384 trace, 355 confirmation,
357 rejected pilot and Fable's dated 620-game reading. It recomputes the raw
score from 339W–27D–254L instead of copying an aggregate table value. Figures
are frozen observations, not current ratings or a new strength claim.

Page one covers six stages of a move, the actual 128→32→2 sample and memory
lifetimes. Page two separates scorer performance, inference quality and play;
it identifies the missing paper components, current strategy selection,
frozen model/table and retired neural policy. It preserves the failed Misty
gate and the separate human authorization for the experimental arena trial.

The first source preflight expected an integer where the pilot stores a list
of unstarted legs. It stopped before creating a document. The importer now
checks that list's length. The initial error is retained; the original pilot,
its outcomes and all source data are unchanged.
